# Contributing

1. Never commit to `main`. Make a branch: `git switch -c feature/short-description`
2. Copy a template from `app/views/_templates/` into `app/views/apply/` and edit it.
3. Add the page to [PAGE-MAP.md](PAGE-MAP.md).
4. Check it with `npm run dev`.
5. Push and open a pull request. Get one approval, then squash merge.

Fake data only. No names or personal details in branches, commits or pull requests.
