# Components

Use [GOV.UK Design System](https://design-system.service.gov.uk/components/) components only. No custom CSS or JavaScript.

| Macro | Used for |
| --- | --- |
| `govukRadios` | Choose one option |
| `govukInput` | Short text answer |
| `govukButton` | Continue and submit |
| `govukBackLink` | Back |
| `govukSummaryList` | Check your answers |
| `govukPanel` | Confirmation |
| `govukErrorSummary` | Errors |

Add a row when you use a new component.
